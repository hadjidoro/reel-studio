# Attribution

The notes in `reference/motion/` are adapted, condensed and translated to Reel Studio's own engine from iart-ai's open motion skills:

- Collection: https://github.com/iart-ai/motion-skills

The packs used, with the skills drawn from:

| Pack | Skills used |
|---|---|
| https://github.com/iart-ai/tiktok-video-skills | short-form-video, caption-animation |
| https://github.com/iart-ai/kinetic-typography-skills | kinetic-typography |
| https://github.com/iart-ai/ad-video-skills | ad-creative-video, launch-video, testimonial-video |
| https://github.com/iart-ai/ecommerce-video-skills | promo-video, photo-slideshow, product-demo-video |
| https://github.com/iart-ai/motion-design-skills | animation-principles, shot-composition, beat-sync-editing, color-motion |
| https://github.com/iart-ai/freelance-motion-skills | video-delivery-specs, creative-brief |

No code was copied. The source code samples target other renderers; only the techniques and numbers were carried over.
